# Управление В — GitHub Pages

Готовый одностраничный сайт в стиле скриншота.

## Как опубликовать

1. Создай новый репозиторий на GitHub, например `upravlenie-v`.
2. Загрузи в него `index.html` и `style.css`.
3. Если хочешь фон как на макете, положи изображение под именем `background.jpg` в корень репозитория.
4. Открой **Settings → Pages**.
5. В разделе **Build and deployment** выбери **Deploy from a branch**.
6. Выбери ветку `main` и папку `/ (root)`, затем **Save**.
7. Через некоторое время GitHub выдаст адрес вида:
   `https://ТВОЙ-ЛОГИН.github.io/upravlenie-v/`

Текст, звания, баллы и условия редактируются прямо в `index.html`.
Цвета, размеры и адаптация под телефон — в `style.css`.
